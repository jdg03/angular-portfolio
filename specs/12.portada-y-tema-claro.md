# Portada y tema claro

El usuario aprueba el diagrama cloud azul ampliado para la portada, solicita azul como primera opción y predeterminado, retirar borgoña y añadir tema claro.

- Portada aprobada copiada a public/covers/cloud-architecture.png, 851 × 315. Se conserva completa con proporción 851/315 y sin recorte; el monograma se superpone en la zona inferior izquierda.
- Selector: azul, morado, carbón y claro. HTML prerenderizado inicia con data-theme=navy. Las preferencias guardadas válidas se conservan; borgoña y otros valores retirados se migran al azul.
- Tema claro con color-scheme light, superficies claras, textos oscuros y acento azul. Roles de texto y etiquetas extraídos a variables para evitar colores claros fijos.
- DESIGN.md y sidecar actualizados.

Validación: build de producción y dos rutas prerenderizadas, tres pruebas unitarias correctas y ocho comprobaciones de navegador correctas. Se verificaron preferencia inicial y migración, imagen/proporción, restauración de tema claro y menú móvil. Los pares de texto/controles revisados en tema claro superan contraste 4.5:1. Evidencias en .artifacts/cover-light-results.json y cover-*.png.
