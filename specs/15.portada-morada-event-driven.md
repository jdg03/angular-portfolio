# Portada morada orientada a eventos

El usuario solicita sustituir la portada morada sin nombres por una arquitectura diferente, orientada a eventos.

Se genera una nueva imagen con imagegen integrado: Client, API Gateway, Event Producer, Event Bus, consumidores Orders/Payments/Notifications, bases de datos separadas, Email, Dead Letter Queue y Observability (Logs, Metrics, Traces). Paleta morada predominante. Se conserva la ruta pública cloud-architecture-purple.png para que el tema morado cargue la nueva versión automáticamente.
